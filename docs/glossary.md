# Glosario de TerraPlan

Términos de la operación explicados sin jerga técnica, para quien usa o valida el sistema desde la
química ambiental.

| Término | Qué significa |
|---|---|
| **Campaña de muestreo** | Un viaje planificado a un sitio para tomar muestras de agua en una fecha y hora determinadas. |
| **Sitio** | Lugar específico donde se toma la muestra, por ejemplo "Río Maipo en Puente Maipo". Tiene código, coordenadas y tipo de cuerpo de agua. |
| **Parámetro** | Propiedad del agua que se mide: pH, turbidez, oxígeno disuelto, nitratos, etc. |
| **Ventana factible** | Rango de horas en el que se puede tomar la muestra **y** alcanzar a dejarla en el laboratorio antes de que la muestra se degrade. Si la muestra llegaría tarde, la ventana no es factible. |
| **Tiempo de conservación** (*holding time*) | Cuánto aguanta una muestra desde que se toma hasta que se analiza sin que cambie su composición. Cada parámetro tiene el suyo y el sistema usa el más corto de la campaña. |
| **Reserva atómica** | Reservar técnico, equipo y vehículo **al mismo tiempo**: si uno de los tres no está disponible, no se reserva ninguno. |
| **Técnico**, **equipo**, **vehículo** | Los tres recursos que se reservan para una campaña. |
| **Reserva liberada** | Reserva que se anuló porque la campaña se canceló o se reprogramó; deja de bloquear el recurso pero queda en el historial. |
| **Reprogramar por clima** | Mover la campaña a otra fecha porque llovió demasiado, el caudal no es el adecuado o el pronóstico no permite muestrear con seguridad. |
| **Caudal** | Cantidad de agua que pasa por el sitio en un momento dado. Si es muy bajo o muy alto, algunos parámetros no se pueden medir. |
| **Bitácora** | Registro de todo lo que pasó con una campaña: se creó, se reservaron recursos, se reprogramó, se publicó. |
| **Límite normativo** | Valor máximo o mínimo permitido por la norma (por ejemplo NCh 1.333 o D.S. 53/2014) para un parámetro en un contexto dado. |
| **Pendiente de validación** | El límite está cargado en el catálogo pero el químico todavía no confirmó el valor. La interfaz lo muestra explícitamente; no debe citarse como oficial. |
| **Dato censurado** | Medición por debajo del límite de cuantificación: se guarda como `< 0,5 mg/L` (sin valor numérico) en lugar de inventar un número. |
| **Publicar** | Enviar los resultados de la campaña al sistema AquaMetric, que los almacena junto al resto del monitoreo. |
| **Catálogo** | Lista compartida de parámetros, unidades y límites, versionada en el repositorio y usada por TerraPlan y AquaMetric para que ambos hablen del mismo dato. |
