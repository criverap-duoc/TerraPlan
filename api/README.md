# TerraPlan API

API NestJS (prefijo `/api/v1`) del proyecto TerraPlan. La documentación general del monorepo
(stack, quickstart y estado de las rebanadas) está en el [`README.md`](../README.md) de la raíz.

```bash
pnpm --filter api start:dev   # http://localhost:3000/api/v1/health
pnpm --filter api test        # tests unitarios
```
